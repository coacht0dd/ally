# Ally Air & Refrigeration — website

Commercial refrigeration and residential HVAC · Dacula, Georgia.

`index.html` is the approved-direction demo homepage (v3, "trust register").
Single self-contained file — no build step, no external assets beyond Google Fonts.

## What's in it

Daylight photo hero with the content on a white card, proof above the fold
(5.0 Google rating, a verbatim customer review, the owner named, credential
strip), then equal-weight doors into commercial refrigeration and residential
heating & air. Refrigeration is named first throughout.

## Ground rules

- Real Google reviews only, quoted verbatim. Never write one.
- No `aggregateRating` schema — stars show visually, ratings come via the
  Google Business Profile.
- One `<h1>` per page.
- Prices stay blank until Ben sets them.
- Never invent a licence number, certification, founding date or statistic.
